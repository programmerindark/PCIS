# Why this file exists rather than using requirements.txt: that one pulls
# PySide6, a full Qt toolkit of a few hundred megabytes, needed only by the
# desktop GUI suites which CI excludes because they require a display.
# Installing it to run tests that never import it wastes minutes on every
# push.
#
# Why it exists rather than just `pip install pytest`: that was the first
# attempt, and it passed locally while failing in CI. The local sandbox
# already had these installed, so the command looked verified when it was
# only untested. Three suites failed to collect -- test_db (SQLAlchemy),
# test_ecowitt_placement (httpx, via backend.app.ecowitt) and
# test_pdf_report (reportlab). Listing dependencies explicitly is what
# makes "it passes on my machine" mean something.
#
# The ENGINE itself (pcis/core, pcis/equipment) is pure standard library.
# Every entry below is pulled in by a TEST or by the web layer, never by
# the climate maths.
